# Pepper.Ninja

Адаптивный промо-лендинг для сервиса Pepper.Ninja, сфокусированный на рекламных кабинетах, партнерской программе и API/White Label предложении. Проект показывает, как через компактную frontend-реализацию собрать выразительную посадочную страницу с интерактивной навигацией, промо-сценариями и акцентным визуальным стилем.

## Основные возможности

- Hero-блок с автоматическим слайдером промо-предложений.
- Фиксированная шапка с навигацией по ключевым секциям страницы.
- Мобильное меню с блокировкой прокрутки фона при открытии.
- Плавный скролл к разделам лендинга.
- Адаптивная сетка контентных блоков для desktop, tablet и mobile.
- Карточки преимуществ, партнерской программы и рекламных сценариев.
- Контактные ссылки, социальные иконки и ссылки на документы в футере.

## Стек

HTML5, CSS3, JavaScript, jQuery, Swiper, Google Fonts.

## Особенности реализации

- **Frontend-only фокус.** Проект реализован как статический лендинг без сборщика и серверной части, поэтому его можно открыть напрямую в браузере или быстро разместить на GitHub Pages.
- **Адаптивная верстка.** Макет перестраивается через CSS Grid, Flexbox и медиазапросы: отдельные состояния предусмотрены для широких экранов, планшетов и мобильных устройств.
- **Интерактивная навигация.** Header остается доступным при прокрутке, якорные ссылки ведут к нужным секциям с плавной анимацией, а мобильное меню корректно закрывается после выбора пункта.
- **Визуальная система.** В проекте используется единая палитра, CSS-переменные, акцентная типографика Roboto Flex, градиентные блоки и подготовленные raster/SVG-ассеты.
- **Промо-сценарии на странице.** Лендинг не ограничивается одним экраном: он раскрывает предложение через hero, объясняющий блок, преимущества, партнерскую механику, API-раздел и финальный CTA.

## Запуск проекта

Откройте `index.html` в браузере.

Для локального сервера можно использовать любой статический сервер, например:

```bash
npx serve .
```

## Статус проекта

Коммерческий frontend-проект, сфокусированный на адаптивной верстке, UI-композиции и базовой интерактивности лендинга.
